# Cyber Garden Testbed

Учебный Kotlin/Spring Boot проект с **7 намеренными находками** для Cyber Garden. Все пароли, API-ключ и закрытый ключ фиктивные. Синтетическая зависимость `garden.training:demo-codec` находится в локальном подпроекте; запись TRAINING-001 — учебная, не реальная CVE.

## Проверка в Cyber Garden

1. Нажмите «Импорт проекта из GitHub» и вставьте URL этого репозитория либо выберите его локальную папку через «Открыть папку».
2. Через «Открыть сценарий» загрузите `workflow.json` из локального клона. Импорт GitHub загружает исходники, но не JSON сценария.
3. Выберите `advisories.json` как справочник; для этой зависимости подходит и встроенный справочник.
4. Нажмите «Запустить». Сценарий не требует модели и webhook.

| Правило | Количество | Критичность | Причина |
|---|---:|---|---|
| secret.literal | 2 | high | Пароль БД и API-ключ в YAML |
| secret.private-key | 1 | critical | Фиктивный заголовок закрытого ключа |
| sca.range | 1 | high | Учебная версия demo-codec 1.1.0 |
| spring.public | 1 | high | Все маршруты открыты |
| spring.csrf | 1 | medium | CSRF отключён |
| sql.parameter | 1 | high | Конкатенация пользовательского ввода в SQL |

## Автоматическая проверка совместимости

Из корня этого репозитория (Node.js 22+):

```powershell
node scripts/verify.cjs ../hackgarden2026-main/garden
node ../hackgarden2026-main/garden/cli.cjs . workflow.json advisories.json
```

Первая команда завершается с кодом 0, когда найдены все 7 ожидаемых проблем. CLI завершится с кодом **1** из-за намеренной critical-находки; это ожидаемый результат теста. Код 2 означает ошибку выполнения сценария.

## Запуск приложения отдельно

Для анализа сборка не нужна. Для отдельного запуска необходимы JDK 17 и установленный Gradle 8.6+:

```powershell
gradle bootRun
```

Проверка: `http://127.0.0.1:8087/health` и `http://127.0.0.1:8087/notes?owner=demo`. Gradle Wrapper в репозиторий не включён. Учебный сервер привязан к localhost; предназначен только для локальных тестов.
